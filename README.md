# デビュー前の彼らに出会う件【マンネ編】

2015年、6歳10ヶ月でSMに入所したナオ。年齢は最年少（マンネ）、入所順は全員の先輩。
女であることを隠して男子練習生として生きる二重生活と、2023年のLASTART選抜、
そして2028年の公表までを描く、スマホ風SNSフィクションゲーム。

- プレイ: https://v5m44g26fb-sudo.github.io/lastart-manne/
- 現行版: v30（2026-11-27）

## v30 変更記録（リアル化 第3弾＝操作の手触り・応答の質）

全画面を Playwright 実駆動で棚卸しし、実害のあるものから修正（表示と操作感のみ。物語テキスト・数値設計・閾値・エンディング条件・セーブ形式 lastart-manne-v1＋undo キーは不変、新しい保存項目なし）。

- シートのドラッグ閉じ（新規）: grab ハンドル／見出しを下へ引くとシートが指に付いて下がり、暗転が比例して薄くなる。90px 超で離すと既存の v23/v24 退場スライド（現在位置を引き継ぐ）で閉じ、短い引きは .25s でスナップバック。ドラッグ域は grab＋見出しのみ（本文スクロールは奪わない）、見出し内のボタンは対象外、reduced-motion（a11y 設定／OS）では無効。実装は `bindSheetDrag`（ovl から接続）。
- コメントシートの入力フォーカス: IG（openIgComments）／TikTok（openTTComments）のコメントシートが開いた瞬間に入力欄へフォーカス（従来は BODY のままで実測）。タップのハンドラ連鎖内で同期実行＋入場 .28s 後に再確認。
- 押下フィードバックの残件: シート×ボタンと投稿／送信（.snd）にタブバーと同じ opacity .4、検索結果行（.srch-hit）にリスト行の #f0f0f3、通知バナー（#bnr）に scale(.985)、プロフィール設定の決定ボタン（.pc-go）に scale(.985)／リセットに opacity .5 を追加（×とフォーカスは実測で無反応を確認してから）。
- スクロールの慣性: .home-scroll／.tt-feed／.sheet .sh-b／.ttp-grid に .abody・チャット本文と同じ -webkit-overflow-scrolling:touch を統一。
- 差分なしと確認した観点: 選択肢は 450ms ガード（actAt）＋snapUndo 前の単発適用、進行は busy ロックで連打しても二重に進まない（実測対象として確認）。SE は送信／受信／確定いずれも単発で重なりなし。長押しメニュー（トーク／ルーム）、スワイプ行アクション、ホーム編集モード、着信まわりの振動は既存実装で実物相当のため据え置き。表示だけの行（名簿カード・ノート・カレンダー）は v19 の判断どおり据え置き。
- 設定画面のバージョン行が v28 のまま止まっていた表示ずれを v30 に是正（タイトル／About は従来どおり更新）。
